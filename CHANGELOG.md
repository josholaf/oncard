# Changelog

## 2.0.0+11

- New card browser: search across question, answer, note and tags
- Filters for All, Due, New and Lapsed cards
- Multi-select with bulk move to deck, bulk tag add/remove and bulk delete
- Entries from the deck screen and the library screen
- Flip-only study mode: quiz and typing modes removed
- Full-year study heatmap with month labels, sized to fit any width
- Native-voice text to speech (device voice, no pinned language)
- lib reorganized into data, services and ui layers
- Windows build removed, Android only
- Home-screen widget: streak, heatmap and deck shortcuts

## 1.0.9

- Image and audio attachments on cards
- Cloze deletions with Anki-style markers
- Image occlusion
- 2,000+ Lucide deck icons with color tinting
